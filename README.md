AI Prompt Library for Project Managers & Finance Professionals

1. Executive Project Status Report
Prompt:
Act as a PMO Manager. Using the project updates below, create a one-page executive report highlighting project health (Red/Amber/Green), completed milestones, key risks, budget status, resource concerns, decisions required, and next steps. Use concise executive language.
________________________________________
2. Risk Register Review
Prompt:
Review the following project risks. Rank them by probability and business impact, identify missing risks, recommend mitigation actions, assign suggested owners, and highlight which risks should be escalated to senior management.
________________________________________
3. Financial Variance Analysis
Prompt:
You are a Finance Business Partner. Analyze the following actual versus budget results. Explain major variances, identify likely business drivers, recommend corrective actions, and summarize the information for an executive audience.
________________________________________
4. Meeting Minutes
Prompt:
Convert these meeting notes into professional minutes with attendees, decisions made, action items, owners, deadlines, unresolved issues, and risks.
________________________________________
5. Executive Email Draft
Prompt:
Rewrite this email for senior executives. Make it concise, professional, solution-oriented, and focused on decisions rather than operational details.
________________________________________
6. KPI Dashboard Summary
Prompt:
Review these KPIs and create a one-page executive summary explaining performance trends, exceptions, opportunities, and recommended actions without simply repeating the numbers.
________________________________________
7. Portfolio Review
Prompt:
Review this project portfolio and identify projects that require executive attention based on schedule, budget, risk, dependencies, and resource utilization. Recommend priority actions.
________________________________________
8. Process Improvement
Prompt:
Review this business process and identify bottlenecks, duplicate work, unnecessary approvals, automation opportunities, and recommendations to improve efficiency.
________________________________________
9. Stakeholder Communication
Prompt:
Create a stakeholder communication plan showing who should receive updates, communication frequency, preferred channels, key messages, and escalation paths.
________________________________________
10. Lessons Learned
Prompt:
Analyze this completed project and produce a Lessons Learned report covering successes, challenges, root causes, recommendations, and actions to improve future projects.
